# Controle Financeiro Pessoal

Projeto desenvolvido em Python para praticar lógica de programação e construir progressivamente um sistema de controle financeiro.

A aplicação funciona no terminal e permite registrar receitas, despesas e consultar o saldo acumulado durante a execução.

## Objetivo

Desenvolver um sistema simples de controle financeiro, utilizando os conhecimentos adquiridos ao longo dos estudos de Python.

O projeto será evoluído gradualmente, incorporando novos conceitos e funcionalidades conforme o aprendizado.

## Funcionalidades atuais

* Registrar receitas.
* Registrar despesas.
* Consultar saldo acumulado.
* Manter o programa em execução através de um menu interativo.
* Encerrar a aplicação.

## Tecnologias

* Python

## Conceitos praticados

* Variáveis.
* Entrada e saída de dados.
* Conversão de tipos.
* Operadores matemáticos.
* Estruturas condicionais.
* Estrutura de repetição `while`.
* Manipulação de strings.

## Como executar

1. Clone o repositório:

   
   git clone https://github.com/gracianokaue/controle-financeiro-python
   

2. Acesse a pasta do projeto:

   
   cd controle-financeiro-python
   

3. Execute o programa:

   
   python main.py
   

## Status do projeto

**Versão 0.1.0 — Fundamentos**

A primeira versão funcional foi concluída utilizando os conceitos estudados até o momento.

## Limitações conhecidas

* Os dados são mantidos apenas durante a execução do programa.
* O sistema armazena somente os totais de receitas e despesas.
* Ainda não existe histórico individual das movimentações.
* Entradas inválidas podem gerar erros de conversão.
* Não há persistência de dados em arquivos ou banco de dados.

## Próximas evoluções

* Tratamento de erros de entrada.
* Armazenamento individual das movimentações.
* Organização do código em funções.
* Persistência dos dados em arquivos.
* Integração com banco de dados SQL.
* Desenvolvimento de relatórios e análises financeiras.
